Uptick · Support

Keep your progress moving.

Before an update or device change

Open Game settings → Export backup and save the JSON file to Files. Keep that file somewhere safe.

Restoring progress

Use Restore backup, choose your saved JSON file and review it before confirming.

Premium on a new device

Open Game settings → Restore purchase while signed in with the same Apple ID that bought Premium.

If the app stops responding

Close and reopen the app. Your progress saves every second and whenever you leave the app. If the problem repeats, copy a bug report below and share it with a description of what you tapped.

About the game

All balances, investments and returns are fictional game mechanics. No money is deposited, invested or withdrawn.

Contact

Questions, problems or ideas: contact the developer through the App Store page for Uptick. Please include the bug report from Game settings → Support & bug report and a description of what you tapped.
